# LJT-Homepage

Personal academic homepage of Junteng Liu, first-year PhD candidate at the HKUST NLP Group.

The site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Contents

* `_config.yml` - site-wide settings and author profile (sidebar)
* `_pages/about.md` - home page: biography, research interests, education, research experience, skills, publications, honors and contact information
* `_pages/cv.md` - CV
* `_pages/publications.html` and `_publications/` - publication list and individual publication pages
* `_data/navigation.yml` - header menu
